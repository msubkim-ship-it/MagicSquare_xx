## 5. 기술 메모

### `tests/entity/__init__.py` shadowing

빈 `tests/entity/__init__.py`가 있으면 `import entity`가 `src/entity` 대신 테스트 디렉터리를 가리켜 `entity.locator` ImportError가 난다.  
**규칙:** `tests/entity/` 아래 **`__init__.py` 두지 않기**.

### 구현 스케치

```python
for row in range(GRID_SIZE):
    for col in range(GRID_SIZE):
        if grid[row][col] == BLANK_CELL:
            coords.append((row + COORD_ONE_BASE, col + COORD_ONE_BASE))
```
