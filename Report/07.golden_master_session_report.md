## 6. 기술 메모

### 패키지 shadowing

`tests/{entity,control,boundary}/__init__.py` 가 있으면 `src/` 동명 패키지를 가려 `ModuleNotFoundError` 발생.  
**규칙:** 테스트 디렉터리 아래 `__init__.py` 두지 않기.

### GRID_SIZE 이중 SSOT

`entity/constants.py` 와 `boundary/constants.py` 에 각각 `GRID_SIZE=4`. REFACTOR 시 control 경유 통합 권장.
